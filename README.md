# CrossApp
Наскрізний проєкт з крос-платформного програмування.

## Предметна область
**Склад.** Сутності: Customer (клієнт), Product (товар), Order (замовлення), 
OrderLine (рядок замовлення).
Призначення: оформлення замовлень і підрахунок сум.

## Структура проєкту
Проєкт розділено на два основні модулі:
* `Cli` — консольний інтерфейс користувача.
* `Core` — бібліотека спільної логіки. У майбутньому тут будуть розміщені каталоги: `Core/Dto` (формати даних), `Core/Domain` (сутності з поведінкою) та `Core/Storage` (реалізації сховищ).

## Запуск та публікація
* Збірка: `dotnet build`
* Запуск: `dotnet run --project src/Cli`
* Публікація: `dotnet publish src/Cli -c Release -r win-x64`

## Аналіз режимів публікації
Різниця між режимами:
* **Framework-dependent**: містить лише код застосунку та залежності, тому має малий розмір, але вимагає встановленого .NET Runtime на машині користувача.
* **Self-contained**: включає повну копію .NET Runtime для конкретної ОС, тому займає багато місця, але може працювати на комп'ютері без встановленого .NET

| RID | Режим | Розмір publish | Потрібен runtime |
|---|---|---|---|
| win-x64 | self-contained | ~76.7 МБ | ні |
| win-x64 | framework-dependent | ~0.2 МБ | так (.NET 10) |

## Середовище
.NET SDK 10.0, Windows 10 x64
